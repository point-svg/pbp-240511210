# Analisis Platform Aplikasi

## 1. Tabel

| Aspek | Web | Desktop | Mobile |
|---|---|---|---|
| Bahasa utama | HTML untuk menyusun halaman, CSS untuk mengatur tampilan, serta JavaScript untuk menambahkan interaksi | C# dan .NET, Java, C++, atau Python untuk membangun program komputer | Kotlin dan Java untuk Android, Swift untuk iOS, serta Dart dengan Flutter untuk aplikasi lintas platform |
| Arsitektur | Interface ditampilkan melalui browser dan dapat mengambil atau mengirim data ke server | Aplikasi diproses oleh sistem operasi komputer dan dapat menggunakan layanan maupun penyimpanan lokal | Aplikasi berjalan pada sistem operasi perangkat seluler dan dapat terhubung dengan server melalui API |
| Cara distribusi | Pengguna membuka aplikasi melalui alamat website tanpa memasang program secara terpisah | Pengguna mengunduh dan memasang paket aplikasi yang sesuai dengan sistem operasinya | Pengguna memasang aplikasi melalui toko aplikasi atau paket instalasi yang didukung perangkat |
| Keunggulan | Dapat digunakan melalui berbagai perangkat yang memiliki browser dan lebih mudah diperbarui dari sisi server | Dapat digunakan untuk pekerjaan kompleks serta mendukung pengelolaan file dan integrasi dengan perangkat komputer | Mendukung penggunaan saat bepergian dan dapat memanfaatkan kamera, GPS, notifikasi, serta sensor perangkat |
| Keterbatasan | Penggunaan fitur tertentu bergantung pada dukungan browser dan akses jaringan apabila aplikasi memerlukannya | Distribusi dan pemeliharaan perlu memperhatikan kompatibilitas dengan sistem operasi pengguna | Pengembang perlu memperhatikan perbedaan perangkat, ukuran layar, konsumsi baterai, dan versi sistem operasi |
| Contoh aplikasi | Google Classroom versi web | Visual Studio Code | Google Maps pada smartphone |

## 3. Refleksi

Dari ketiga platform yang dipelajari, saya paling tertarik pada Mobile karena ingin mengetahui proses pembuatan aplikasi Android dari sisi pengembang. Selama ini, saya lebih sering melihat smartphone sebagai alat untuk menjalankan aplikasi. Melalui pembelajaran ini, saya ingin mulai memahami bagaimana sebuah aplikasi dibuat, mulai dari penulisan kode hingga dapat digunakan pada perangkat. Menurut saya, mempelajari Android juga dapat menjadi bekal untuk mengembangkan proyek yang berkaitan dengan kebutuhan sehari-hari.

Menurut saya, hal yang perlu diperhatikan saat menyiapkan *environment* bukan hanya mengunduh dan memasang program, tetapi juga memahami fungsi setiap *tools*. Git digunakan untuk mengelola perubahan kode, Node.js dan NPM mendukung pengembangan berbasis JavaScript, sedangkan Java JDK dan Android Studio digunakan dalam pengembangan Android. Karena setiap *tools* memiliki fungsi yang berbeda, saya perlu memastikan semuanya terpasang dan berjalan sesuai kebutuhan. Saya juga perlu memperhatikan kapasitas penyimpanan agar proses instalasi tidak terganggu.

Untuk menghadapi tantangan tersebut, saya akan menyiapkan *environment* secara bertahap dan memeriksa setiap instalasi sebelum melanjutkan ke tahap berikutnya. Saya akan mengecek instalasi melalui terminal, mencoba mengelola proyek menggunakan Git, lalu membuat proyek Android sederhana di Android Studio. Jika muncul kesalahan, saya akan memeriksa pesan *error* terlebih dahulu sebelum mencari solusi melalui dokumentasi resmi. Saya berharap proses ini dapat membantu saya menjadi lebih mandiri ketika menghadapi masalah teknis dalam mengembangkan aplikasi.
